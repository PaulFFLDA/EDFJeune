# 🇫🇷 France Lutte Jeunes

Application Streamlit de suivi des jeunes lutteurs français.

## Fonctionnalités

### Lutteur / Lutteuse

- Tableau de bord individuel
- Fiche récapitulative
- Calendrier personnel
- Compte-rendu rapide des compétitions
- Nombre de combats
- Victoires / défaites
- Classement
- Bilan de compétition
- Suivi du poids
- Courbe de poids
- Tests physiques
- Évolution des tests

### Entraîneur / Club

- Liste des lutteurs
- Fiches individuelles
- Suivi des compétitions
- Tests physiques
- Calendrier

### Sélectionneur / Staff

- Vue nationale
- Collectifs
- Fiches individuelles
- Planning national
- Stages
- Compétitions
- Tests physiques

### Administration

- Vue globale
- Liste des lutteurs
- Fiches
- Statistiques
- Planning
